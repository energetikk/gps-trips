# Сайт: онлайн-карта и история поездок

Мини-сервер для приложения «GPS Поездки»: принимает текущие координаты и
историю поездок, а страница показывает карту Яндекса с онлайн-положением и
списком маршрутов.

Без зависимостей и без npm: только Node.js 20+ и стандартная библиотека.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `server.js` | HTTP API: координаты, поездки, пароль на просмотр, статика для локального запуска |
| `web/index.html` | Страница с вкладками «Сейчас» и «История» |
| `Dockerfile` | Образ приложения |
| `docker-compose.yml` | `api` (Node) + `web` (Nginx) |
| `nginx.conf` | Проксирование `/api/` в Node и раздача статики |
| `.env.example` | Шаблон настроек |

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| `POST` | `/api/position` | Текущая точка. Заголовок `X-Token` обязателен |
| `POST` | `/api/trips` | Загрузка/обновление одной поездки. `X-Token` обязателен |
| `GET` | `/api/last` | Последняя точка и трейл (до 300 точек) |
| `GET` | `/api/trips` | Список поездок без треков |
| `GET` | `/api/trips/{id}` | Одна поездка с треком |
| `GET` | `/api/health` | Проверка живости и счётчик поездок |

Текущая точка:

```json
{"lat": 56.326123, "lon": 44.002456, "speed_kmh": 42.5, "ts": 1794522347168, "device": "car"}
```

Поездка (трек — компактные массивы `[время, широта, долгота, скорость]`):

```json
{
  "id": "2025-11-12.nmea@1700000000000",
  "source": "2025-11-12.nmea",
  "device": "car",
  "startMs": 1700000000000,
  "endMs": 1700000600000,
  "distanceM": 12345.6,
  "movingSec": 2600,
  "maxSpeedKmh": 98,
  "avgSpeedKmh": 62.4,
  "timeReliable": true,
  "track": [[1700000000000, 56.326, 44.002, 40], [1700000015000, 56.327, 44.003, 42]]
}
```

Успех — `204 No Content`. Повторная отправка поездки с тем же `id` заменяет её.

Если задан `VIEW_PASSWORD`, `/api/last`, `/api/trips` и страница требуют этот
пароль (страница спрашивает его один раз и держит в `sessionStorage`).

## Хранение данных

- `state.json` — последняя точка и трейл (онлайн).
- `trips.json` — история поездок (до 5000 поездок, до 2000 точек в треке).
- Оба файла лежат в томе `state` Docker Compose (`/data`), переживают
  перезапуск контейнера. Резервная копия — скопировать том или папку `/data`.
- Запись атомарная (временный файл + переименование), с задержкой 2 секунды,
  чтобы пачка поездок не писала диск на каждый запрос.

## Быстрый запуск без Docker

```powershell
$env:TRACK_TOKEN = "длинный-случайный-токен"
$env:PUBLIC_DIR = "$PWD\web"
$env:PORT = "8080"
node server.js
```

Откройте `http://localhost:8080`. Отправить тестовую точку:

```powershell
$body = '{"lat":56.326123,"lon":44.002456,"speed_kmh":42.5,"device":"car"}'
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/position `
  -Headers @{ "X-Token" = "длинный-случайный-токен" } `
  -ContentType "application/json" -Body $body
```

## Запуск на VPS (Docker Compose + Nginx)

1. Скопируйте папку `server` на сервер, например в `/opt/gps-tracker`.
2. Создайте `.env` рядом с `docker-compose.yml`:

   ```bash
   cd /opt/gps-tracker
   cp .env.example .env
   # отредактируйте TRACK_TOKEN (и при желании VIEW_PASSWORD, HTTP_PORT)
   ```

3. Запустите:

   ```bash
   docker compose up -d --build
   ```

4. Nginx слушает порт `HTTP_PORT` (по умолчанию `8080`) и проксирует `/api/`
   в Node. Проверьте:

   ```bash
   curl -s http://127.0.0.1:8080/api/health
   curl -s -X POST http://127.0.0.1:8080/api/position \
     -H 'X-Token: ваш-токен' -H 'Content-Type: application/json' \
     -d '{"lat":56.32,"lon":44.0}'
   curl -s http://127.0.0.1:8080/api/trips
   ```

### HTTPS

Нужен обязательно: токен устройства передаётся в заголовке. Варианты:

- поставить перед контейнером Caddy/Traefik или уже имеющийся Nginx с
  сертификатом Let's Encrypt и проксировать на `127.0.0.1:8080`;
- либо добавить TLS прямо в `nginx.conf` и смонтировать сертификаты.

Тогда в приложении адрес сервера — `https://ваш-домен`.

## Настройка приложения

На экране «Настройки» → «Передача координат на сайт»:

- **Адрес сервера** — например `https://ваш-домен` (пути `/api/position` и
  `/api/trips` приложение добавляет само; полный адрес тоже понимается);
- **Токен устройства** — значение `TRACK_TOKEN` с сервера;
- **Имя устройства** — метка, которая видна на странице;
- **Интервал** — как часто отправлять координаты (2–60 секунд);
- **История: вкл/выкл** — выгружать поездки; кнопка «Отправить поездки»
  запускает выгрузку вручную.

После «Включить передачу» приложение запускает foreground-сервис, читает
последний по времени лог GPS из выбранной папки и отправляет новые точки.
Если новых точек нет (стоянка), раз в минуту уходит последняя известная —
чтобы страница оставалась «на связи».

История выгружается после каждого обновления списка поездок: отправляются
только новые поездки и те, чей трек изменился (подпись «конец трека + число
точек» хранится в настройках приложения). Если поменять адрес или токен,
подписи сбрасываются и история уходит на новый сервер заново.

## Ограничения

- Карта на странице — статичная картинка Яндекс.Карт (`static-maps.yandex.ru`,
  без API-ключа): маркер, трейл и маршрут обновляются, но панорамировать
  нельзя. Кнопка «Открыть в Яндекс.Картах» ведёт в полноценную карту.
- Без ключа Static API действует суточный лимит запросов; онлайн-карта
  обновляется только при заметном перемещении (8 м) или смене масштаба.
- История хранится в JSON-файле целиком; при тысячах поездок файл вырастает
  до десятков мегабайт и перезаписывается при изменениях. Для личного
  использования этого достаточно, для больших объёмов стоит перейти на SQLite.
- Пароль на просмотр (`VIEW_PASSWORD`) — общий, без пользователей и сессий.
  Для публичного доступа лучше закрыть страницу на уровне reverse-proxy.
