# Нативные программы для магнитолы

Сборка (нужен NDK 28 в SDK, путь берётся из `local.properties`):

```powershell
powershell -ExecutionPolicy Bypass -File .\native\build.ps1
```

Готовые бинарники кладутся в `native/build/` (в git не попадают).

## Что здесь есть

| Файл | Что делает |
|---|---|
| `src/probe.cpp` | проверка на магнитоле: грузится ли `liblitecamdev.so` и создаётся ли менеджер камер. Камеры не открывает |
| `mock-camd.sh` | заглушка вместо настоящего `camd`: пишет четыре готовых JPEG. Нужна, чтобы прогнать всю цепочку «сайт → магнитола → сайт» без камер |
| `build.ps1` | сборка всех `src/*.cpp` под arm64-v8a / Android 9 |

## Как проверить цепочку без камер

1. Собрать и установить приложение с поддержкой камер (ветка с `Camera.kt`).
2. Положить заглушку на магнитолу:

   ```sh
   su -c "cp /sdcard/mock-camd.sh /data/local/tmp/camd && chmod 755 /data/local/tmp/camd"
   ```

3. На сайте нажать «Снять кадр». Магнитола найдёт `camd` в `/data/local/tmp`,
   запустит его, получит четыре файла и отправит их на сервер.

Заглушка отвечает не сразу, а как настоящий `camd` — запускается по кнопке,
поэтому проверяется и задержка, и обработка ошибок (если убрать `base64`,
в карточке появится текст ошибки с магнитолы).
