# GPS Поездки

Приложение для магнитолы: читает лог внешнего GPS-приёмника (u-blox M9N через
USB), собирает из него поездки, показывает статистику, маршрут на карте Яндекса
и умеет передавать на ваш сайт текущие координаты и историю поездок.

## Что умеет

- разбирает текстовые NMEA-логи (`$xxRMC`, `$xxGGA`, `$PUBX,00` от u-blox) и GPX;
- режет трек на поездки, считает расстояние, длительность, время в движении,
  среднюю и максимальную скорость;
- главный экран: сводка за сегодня / 7 / 30 дней и список поездок по дням;
- экран поездки: цифры, профиль скорости, быстрый обзор трека (● старт, ● финиш);
- **маршрут поездки на интерактивной карте Яндекса** (MapKit) прямо в приложении;
- **передача координат в реальном времени** на ваш сервер — там открыта страница
  с картой Яндекса и текущим положением автомобиля;
- **история поездок на сайте**: приложение выгружает маршруты, страница
  показывает список по дням, статистику и трек выбранной поездки;
- отправка сводки или отдельной поездки в Telegram-бот (в личку или в приватную группу).

## Установка на магнитолу

1. Соберите APK (см. «Сборка из исходников») или возьмите его из артефактов
   GitHub Actions — файл `app-debug.apk`.
2. Скопируйте APK на флешку и откройте файл файловым менеджером на магнитоле
   (или передайте любым удобным способом).
3. Разрешите установку из неизвестных источников, когда система спросит.
4. Либо по adb: `adb install -r app-debug.apk`

Приложение не требует root и не лезет в USB-порт: оно работает с файлом,
который уже пишет приложение GPS-модуля.

## Первый запуск

1. **Настройки → Разрешить доступ к файлам** — на Android 11+ нужно дать
   «Доступ ко всем файлам», иначе папку с логами не прочитать.
2. Укажите папку с логами:
   - «Выбрать папку» — системный диалог (на части магнитол его нет);
   - «Путь вручную» — например `/storage/emulated/0/GPS`.
3. «Обновить» — приложение прочитает все `.nmea`, `.txt`, `.log`, `.gpx`
   из папки и вложенных папок (до 3 уровней).

Проверить работу без реальных логов: скопируйте на магнитолу файл
`sample/demo-20251112.nmea` в любую папку и укажите её — получится две поездки.

## Маршрут на карте Яндекса

На экране поездки нажмите на карту (или на значок «Яндекс.Карта ›» в правом
нижнем углу) — откроется полноэкранная карта MapKit с линией трека, метками
старта и финиша. Камера сразу охватывает весь маршрут, кнопка «Весь маршрут»
возвращает её к треку после ручных жестов.

Для карты нужен ключ MapKit:

1. Войдите в [кабинет разработчика Яндекса](https://developer.tech.yandex.ru/services/)
   и подключите **MapKit — мобильный SDK** (есть бесплатный тариф).
2. В **Интерфейсы API → MapKit — мобильный SDK** добавьте приложение с пакетом
   `ru.gpstrips` и отпечатком SHA-1 ключа, которым подписан APK.
   Для debug-сборки отпечаток берётся так:

   ```powershell
   keytool -list -v -keystore $env:USERPROFILE\.android\debug.keystore `
     -alias androiddebugkey -storepass android -keypass android
   ```

   Для release-сборки добавьте отпечаток вашего релизного ключа.
3. Ключ активируется примерно 15 минут. Задайте его при сборке через переменную
   окружения `MAPKITSDK` (в исходники и git он не попадает):

   ```powershell
   $env:MAPKITSDK = "ваш-ключ-mapkit"
   .\gradlew.bat assembleDebug
   ```

Если ключ не задан, приложение соберётся, но вместо карты покажет подсказку.

## Передача на сайт: онлайн и история

1. На VPS разверните сервер из папки [`server/`](server/README.md):
   `docker compose up -d --build` (Node + Nginx, подробности — в
   [server/README.md](server/README.md)).
2. В приложении откройте **Настройки → Передача координат на сайт** и укажите:
   - **Адрес сервера** — `https://ваш-домен` (пути `/api/position` и
     `/api/trips` приложение добавляет само);
   - **Токен устройства** — значение `TRACK_TOKEN` с сервера;
   - **Имя устройства** — метка для страницы;
   - **Интервал** — 2–60 секунд;
   - **История: вкл** — выгружать поездки (включено по умолчанию).
3. Нажмите «Включить передачу» и разрешите уведомления (Android 13+).

Приложение запускает foreground-сервис: он следит за последним по времени логом
GPS в выбранной папке и отправляет новые точки. Сервис не мешает читать логи и
показывать поездки. Текущее состояние видно на главном экране («передаю
координаты · 12:34:56»).

История выгружается после каждого обновления списка поездок: уходят только новые
поездки и те, чей трек изменился; кнопка «Отправить поездки» в настройках
запускает выгрузку вручную. При смене адреса или токена история отправляется на
новый сервер заново.

На сайте две вкладки:

- **Сейчас** — интерактивная карта с маркером и трейлом, обновление раз в
  2 секунды; карту можно двигать и приближать, есть галочка «следить за точкой»;
- **История** — поездки по дням, при выборе показываются маршрут на
  интерактивной карте (зум, перетаскивание), расстояние, время в пути и в
  движении, средняя и максимальная скорость.

Карта сайта — JavaScript API Яндекс.Карт. Ключ не обязателен, но для
стабильности можно задать `YMAPS_JS_KEY` в `server/.env` (подробнее — в
[server/README.md](server/README.md)).

Если на сервере задан `VIEW_PASSWORD`, страница спросит его один раз.

Проверить историю без реальных поездок можно демо-данными из
[`server/seed.js`](server/seed.js): `node seed.js --base https://ваш-домен`
(убрать — добавить `--clear`).

## Telegram

1. В Telegram у **@BotFather** выполните `/newbot`, задайте имя — получите токен
   вида `1234567890:AAH...`.
2. Создайте приватную группу, добавьте туда бота (бот должен быть участником,
   лучше — с правом отправки сообщений).
3. Узнайте `chat_id`:
   - напишите любое сообщение в группу, откройте в браузере
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
     `"chat":{"id":-1001234567890,...}` — это и есть `chat_id` (у групп он
     отрицательный);
   - для лички — свой числовой id (например через бота `@userinfobot`).
4. В приложении: **Настройки → Telegram** → вставьте токен и `chat_id` →
   «Сохранить» → «Отправить сводку».

Сервер не нужен: приложение само вызывает Bot API, как только появляется интернет.

## Сборка из исходников

Нужен JDK 17 и Android SDK с платформой 34.

```powershell
$env:JAVA_HOME = "C:\path\to\jdk17"
$env:MAPKITSDK = "ваш-ключ-mapkit"   # без него карта будет недоступна
.\gradlew.bat assembleDebug testDebugUnitTest
```

- **Android Studio**: открыть папку проекта и нажать Run.
- **GitHub Actions**: workflow `.github/workflows/build.yml` собирает APK и
  тесты на каждый push, готовый файл — в артефактах сборки. Ключ MapKit
  передаётся секретом `MAPKITSDK` (Settings → Secrets and variables → Actions).

Ключ MapKit встроен в APK, поэтому готовый APK с ключом в репозиторий не
кладётся: его собирают локально или в CI.

## Как считаются поездки

Логика намеренно простая и проверяемая (тесты в `app/src/test`):

- точки сортируются по времени; дубли (две строки в одну секунду), нулевые
  координаты и «телепорты» (сотни метров за пару секунд) отбрасываются;
- пауза больше **5 минут** закрывает поездку, следующая точка начинает новую;
- отрезок короче **300 м** поездкой не считается;
- средняя скорость = расстояние / время, когда скорость была выше 3 км/ч;
- максимальная скорость — 98-й перцентиль, чтобы одиночный выброс приёмника
  не портил цифру;
- если в GPX вместо времени стоит 1970 год (так делают некоторые экспортёры),
  поездка помечается как «время недостоверно» и длительность не показывается.

## Ограничения текущей версии

- APK отладочный (`debug`), подписан debug-ключом — для личного использования
  этого достаточно, для публикации нужен свой ключ.
- MapKit сильно увеличивает размер APK (в сборке есть библиотеки под arm64,
  armeabi-v7a, x86 и x86_64 — около 100 МБ). Это цена нативной карты Яндекса.
- Карта MapKit и тайлы OSM берутся из интернета; без сети остаётся тёмный фон,
  линия трека и метки MapKit.
- Передача координат работает, пока живёт foreground-сервис. На некоторых
  прошивках магнитол агрессивная экономия батареи может его останавливать —
  тогда добавьте приложение в исключения.
- Отправляются только новые строки последнего лога; старые логи и GPX-файлы,
  которые не дописываются, в реальном времени не обновляются.
- История на сайте обновляется при запуске приложения, по кнопке «Обновить»,
  кнопке «Отправить поездки» и автоматически раз в 10 минут, пока приложение
  открыто; сама по себе магнитола с выключенным экраном историю не выгружает.
- Бинарные логи (`ubx`) и CSV не поддерживаются.
